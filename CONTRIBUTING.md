# Contributing to Time to Go

Thanks for your interest in contributing to Time to Go!

## Reporting issues and asking questions

- For **bugs**, use the [Bug report](https://github.com/enegalan/time-to-go/issues/new?template=bug_report.md) template.
- For **feature requests**, use the [Feature request](https://github.com/enegalan/time-to-go/issues/new?template=feature_request.md) template.
- For **questions**, use the [Question](https://github.com/enegalan/time-to-go/issues/new?template=question.md) template.

## Development setup

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run watch` to build on changes.
4. Press `F5` in VS Code to start a new Extension Development Host.

## Pull requests

- Keep changes focused and as small as reasonable.
- Describe the motivation and behavior of the change in the PR description.
- Link any related issues when relevant.
